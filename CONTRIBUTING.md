# Contributing to EduFlow

Thank you for your interest in improving EduFlow. EduFlow is a proprietary product owned by Zaref Technology, and contributions are accepted only with the project owner's approval.

## Before you start

- For significant changes, contact the project maintainers before beginning work.
- Keep changes focused and explain the problem they solve.
- Do not include credentials, API keys, private data, or confidential information in a change.
- Only submit code, documentation, and other materials that you have the right to contribute.

## Making a change

1. Fork the repository or create a feature branch, as appropriate for your access.
2. Install dependencies with `npm install`.
3. Make and test your changes. Run `npm run lint` and, where practical, `npm run build`.
4. Open a pull request with a clear summary, context, and testing notes.
5. Wait for review. A pull request is not accepted until a maintainer approves and merges it.

## Contribution terms

Submitting a contribution does not transfer ownership of the EduFlow product or grant a license to use the product. Any rights or permissions concerning a contribution will be governed by a separate written agreement with Zaref Technology, if applicable. Do not submit a contribution if you are unable to comply with the applicable terms.

## Questions

For contribution questions, contact the project maintainers through the repository's official channels.
